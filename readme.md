## 🌟 Featured Project

### 🩸 BloodLink — ML-Based Blood Donor-Recipient Matching System

An ML-based application designed to assist in matching blood donors with recipients based on multiple compatibility and availability factors.

### 🔬 Key Features

- 🩸 Blood-type compatibility
- 📍 Geographic proximity
- ✅ Donor eligibility
- 🕐 Donation recency
- 🤖 Random Forest classification
- 📊 Feature engineering
- 🗃️ Synthetic dataset generation
- 🌐 Flask-based web application

The project uses a synthetic dataset containing **200 donors and 50 recipients** across major Indian cities.
